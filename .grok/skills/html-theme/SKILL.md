# HTML theme

Read `docs/skills/skill-html-theme.md` and follow it. The procedure lives there. Do not keep a second copy in this file.

The folder name is the stored theme key. The typed name `amminty` is the folder `docs/html-theme/adminty`. A key such as `admindek` is `docs/html-theme/admindek`.

Each theme folder has:

- `assets/css/inventory.md`
- `assets/js/inventory.md`
- `santized.html`

On add or modify, keep the supplied markup. Store each licensed stylesheet and script at the `assets/` path the page already uses. Do not copy a commercial template file, including through a temp directory. Do not change the product shell from this skill.
